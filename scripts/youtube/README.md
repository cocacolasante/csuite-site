# CSuite Code — YouTube scripts

A working set of YouTube scripts for promoting and explaining CSuite Code.
Two folders:

- **`promotional/`** — short brand/explainer videos (60s–3min) for ads,
  LinkedIn, and the channel trailer. Goal: get viewers onto the discovery
  call calendar.
- **`tutorials/`** — longer educational videos (5–12min) that earn trust by
  teaching. These rank in YouTube search, get embedded in blog posts, and
  pull qualified leads through the funnel.

## How to use these scripts

Each file follows the same structure:

| Section | What it is |
| --- | --- |
| **Meta** | Target length, audience, CTA, suggested title/description/tags. |
| **Cold open** | The first 5–10 seconds. Read it punchy — this is where viewers decide to stay. |
| **Body** | Numbered segments with rough timestamps and on-screen / B-roll notes. |
| **Outro** | The CTA you say on camera before the end card. |
| **End-card overlay** | The text/links to show in the last 5 seconds. |

**Reading style:** these are conversational scripts, not stage plays. Use the
bolded phrases as anchors and reword the rest in your own voice if it feels
forced. Pause at em-dashes (—) and breathe at the line breaks.

## Standard CTAs

Reuse these so the channel feels consistent:

- **Primary:** "Book a free 30-minute discovery call — link in the description."
  → `https://calendar.app.google/jSHYj7c6WtJGykGQ7`
- **Nonprofit:** "If you run a 501(c)(3), the call includes a free
  GrantMind Pro walkthrough — same link, just mention you're a nonprofit."
- **Email fallback:** `Info@csuitecode.com`
- **LinkedIn:** `https://www.linkedin.com/company/c-suite-code/`

If you're starting from zero, record in this order — it builds momentum from
shortest/easiest to longest/most evergreen:

1. `promotional/01-what-is-csuite-code.md` — 60-second channel intro.
2. `promotional/02-stop-overpaying-aws.md` — 90-second hook video.
3. `tutorials/01-choose-nonprofit-it-support.md` — long-form authority piece.

## Production notes

- **Camera:** straight to camera, eye-line at the lens. Sit at a slight angle
  so the shot has depth.
- **Audio matters more than video.** A $90 lavalier beats a $900 camera with
  bad audio. View counts forgive grain; they do not forgive hiss.
- **B-roll:** screen-record the relevant page on `csuitecode.com` for cutaways.
  Each script lists the URL to capture. 5–8 seconds per cutaway is plenty.
- **Lower thirds:** every promotional video should show `csuitecode.com` and
  the calendar link as a persistent lower third.
- **End card:** 5-second hold with the discovery-call link, the email, and
  one suggested next video.
